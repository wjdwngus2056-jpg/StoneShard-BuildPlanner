# Stoneshard · 캐릭터 빌드 플래너

실제 게임 아트와 원본 스킬트리를 사용하는 스톤샤드 캐릭터 빌드 플래너입니다. 정적 화면은 Cloudflare Pages, 공개 빌드와 Google 로그인은 Supabase를 사용하는 구성입니다.

## 공개 빌드와 배포

설정 전에도 기존 빌더와 개인 브라우저 저장을 사용할 수 있습니다. 공개 기능을 연결하면 **공개 빌드**에서 캐릭터·이름으로 검색하고, **공개하기**로 현재 빌드와 빌드 설명·최종 장비 계획·티어별 운영 설명을 업로드합니다. 누구나 열람할 수 있으며 로그인한 작성자만 수정·삭제합니다. 공유 주소는 `#build=빌드ID` 형식입니다. 공개 목록에는 습득한 모든 계열의 아이콘·이름·개수를 표시하며 도축과 캐릭터별 무료 시작 기술도 포함합니다. 기존 빌드도 문헌·스탯을 포함한 투자 기록에서 계산하므로 다시 공개할 필요가 없습니다. 편집 화면과 공개 목록의 개수는 전체 습득 수이며, AP 소비·특성 보상은 직접 투자량으로 계산합니다.

다른 사람의 빌드는 읽기 전용으로 열며 개인 초안은 보존합니다. **편집용 복사**로 수정하거나 **내 작업으로 돌아가기**로 기존 편집 상태를 복원합니다. 내 공개 빌드의 업데이트는 **내 공개 빌드 수정 → 편집 → 공개하기 → 기존 빌드 수정**으로 진행합니다.

GitHub 저장소는 [StoneShard-BuildPlanner](https://github.com/wjdwngus2056-jpg/StoneShard-BuildPlanner)입니다. 아직 Supabase/Cloudflare 프로젝트를 연결하지 않았으므로 실제 업로드와 로그인은 활성화되지 않았습니다. 생성할 계정, SQL 적용, Google 로그인과 배포 설정은 [배포 안내](docs/DEPLOYMENT.md)를 따릅니다.

## 열기

`index.html`을 브라우저에서 바로 열면 됩니다. 빌드·패키지 설치·외부 웹 폰트가 필요하지 않습니다. 초상화와 스킬 이미지도 프로젝트에 포함되어 오프라인에서 표시됩니다.

로컬 서버를 사용하려면 이 폴더에서 다음 명령을 실행하세요.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

브라우저 주소: http://127.0.0.1:4173

## 조작

- 실제 초상화를 가진 8명의 캐릭터 선택. 변경 전 빌드는 **되돌리기**로 복원할 수 있습니다.
- 능력치의 `+` / `−`로 선택한 레벨에 투자하거나 기존 투자를 취소합니다.
- 요르그림·벨미르·디르윈의 특성 설명 아래 **특성 최대 보상 적용** 체크로 추가 SP를 반영합니다. 각각 전리품 15종의 첫 반납 보상 +5 SP, 트롤·만티코어 처치 보상 +4 SP, 디르윈 특성 보상 +3 SP를 계산합니다. 기본은 꺼짐이며 체크한 레벨부터 적용합니다. 디르윈의 AP 자동 계산과 SP 적용 여부는 독립적으로 동작합니다.
- 모든 캐릭터가 **환상열석 보상 적용**을 켜고 끌 수 있습니다. 공통 +1 SP에 에메랄드(체력 +5), 사파이어(기력 +5), 루비(물리저항 +4%) 중 선택한 보석의 영구 효과를 더합니다. SP는 능력치 투자에 사용할 수 있으며, 보석 효과는 **추가 영구 효과**로 표시합니다. 보상 해제 후에도 선택한 보석을 기억합니다.
- **레벨별 성장 계획**은 빌드명 아래에 배치합니다. **빌드 설명 → 최종 티어 장비 계획 → 티어별 운영 가이드** 순서로 작성하며, 1~5티어에서는 운영 설명만 작성합니다. 던전 티어를 특정 레벨 구간에 고정하지 않습니다.
- 레벨 선택 바로 아래에 **해당 레벨에 직접 투자한 스탯·스킬**을 작게 표시합니다. 바로 다음 **성장 기록**은 기본으로 접혀 있으며 펼치면 1~30레벨의 스탯·스킬·문헌과 보상을 표로 확인할 수 있습니다. 각 레벨을 눌러 이동해도 펼침 상태와 이후 계획은 유지합니다. 큰 누적 수치 카드는 제거했습니다.
- **빌드 설명**은 티어별 운영 가이드 위에 배치하며 **빌드 특징 / 장점 / 단점**을 각각 작성합니다. 레벨·티어 선택과 독립적으로 유지되고 개인 저장·공개 빌드에 함께 포함됩니다. 기존 빌드는 빈 설명란으로 열립니다.
- **최종 티어 장비 계획**에는 11개 부위의 장비명만 입력합니다. **추천 인챈트 옵션**은 공통 메모 한 칸에 적고, **장비 설명 ( 선택이유 / 교체순서 / 대체장비 등)**을 별도로 작성합니다. 모든 입력은 자동 임시 저장·되돌리기·빌드 저장·공개 업로드에 포함됩니다. 이전 티어 장비 복사 기능은 제거했습니다.
- 기존 티어별 장비는 부위별로 가장 높은 티어의 입력을 최종 계획으로 옮깁니다. 인챈트와 장비 설명도 높은 티어를 우선하며, 원래 입력은 **이전 티어별 장비 기록**에 접어서 보관합니다. 새 계획을 비운 뒤 다시 불러와도 이전 기록으로 덮어쓰지 않습니다.
- 힐다의 특성 아래 **기념품 선택**에서 뼈 부적 효과를 최대 3개 선택합니다. 첨부 표의 12개 효과에 대해 전리품·효과·기본값·최대치를 표시하며, 사슴 뿔·산양 뿔은 같은 기력 효과이므로 한 선택지입니다. 3개를 고르면 선택하지 않은 항목이 비활성화되며 해제하면 다시 선택할 수 있습니다. 선택은 빌드 전체의 계획으로 저장하며 레벨별 습득 기록과는 독립적입니다. 기본값과 최대치를 함께 표시하고 처치 횟수에 따른 현재 수치나 전투 수치 합산은 추정하지 않습니다. 수치·단위는 사용자 제공 표를 따릅니다(체력 +3~+10, 기력 +2~+8은 고정 수치). 동작은 [Bone Charm](https://stoneshard.com/wiki/Bone_Charm)에서도 대조했습니다. 출처는 화면에 표시하지 않습니다.
- 현재 장비 계획은 직접 입력하는 메모입니다. 장비 목록 검색이나 장비 수치의 계산 반영은 아직 포함하지 않습니다. 공식 위키의 [검](https://stoneshard.com/wiki/Swords), [몸통 장비](https://stoneshard.com/wiki/Chestpieces), [반지](https://stoneshard.com/wiki/Rings) 표에서 티어·종류·기본 수치·옵션을 수집할 수 있음을 확인했습니다. 향후 고정 ID로 장비 목록을 가져오고 한국판 명칭을 별도 매핑하면 기존 메모를 유지하면서 검색 선택 기능을 추가할 수 있습니다. 장비 티어와 던전 티어는 분리해서 저장해야 합니다.
- 특성·이벤트를 해제해 포인트가 부족해지면 해당 보너스에 의존하던 능력치·스킬 투자를 정리합니다. **되돌리기**로 보상과 투자 내역을 함께 복구할 수 있습니다. 저장한 빌드에는 보상을 받은 레벨과 보석 선택도 보관됩니다.
- 스킬 아이콘 클릭: 오른쪽 **스킬 효과** 탭에 한국어 효과, 기본 기력·재사용 시간·사거리 등 등록된 정보를 표시합니다. **해금·습득** 탭에서 해금 경로와 선행 조건을 확인하고 **기술 습득 / 습득 취소** 버튼으로 투자합니다.
- 무기 기술 11계열 / 범용 6계열 / 마법 4계열에 원본 트리 21종과 실제 스킬 228개가 있습니다.
- 무기 계열: 검, 도끼, 철퇴, 단검, 양손 검, 양손 도끼, 양손 철퇴, 창, 원거리 무기, 방패, 지팡이.
- 범용 계열: 쌍수 무장, 체술, 생존, 병법, 갑옷 전투, 마법 숙달. 마법 계열: 화염 마법, 대지 마법, 전격 마법, 미지 마법.
- 효과 설명의 근력·민첩성·인지력·생명력·의지력 계수는 현재 선택한 레벨의 기본 능력치로 계산합니다. 장비·버프·전투 상황은 포함하지 않으며, 장비/상황 수치가 필요한 식은 한국어 계산식으로 표시합니다.
- 모든 캐릭터는 **도축**을 무료로 습득한 채 시작합니다. AP를 사용하지 않고 습득 취소도 불가능합니다. 기존 빌드에서 유료로 찍었던 도축은 불러올 때 자동으로 무료 기술로 전환하고 AP를 반환합니다.
- 스킬 노드를 한 번 클릭하면 효과와 조건을 확인하고, **더블클릭하면 습득·취소**합니다. 첫 클릭에서 노드를 재생성하지 않아 브라우저의 더블클릭 동작을 유지합니다. AP·해금·선행 조건은 상세 패널의 습득 버튼과 동일하게 적용하며, 무료 시작 기술은 취소할 수 없습니다. 선행 기술 취소에 따른 하위 기술 정리와 되돌리기도 기존과 같습니다.
- 하단에서 1~30레벨을 선택하면 해당 시점의 능력치와 습득 스킬을 표시합니다. 미래의 투자 내역은 보관합니다.
- 선행 조건이나 포인트가 부족해지는 변경은 이후의 유효하지 않은 투자를 정리합니다. 되돌리기로 복구할 수 있습니다.
- **해금·습득** 탭에서 문헌과 능력치 경로를 함께 표시합니다. **이 문헌을 Lv.N에 읽기** 버튼은 선택한 레벨에 해당 계열·등급의 문헌을 읽은 것으로 기록하며 AP를 사용하지 않습니다.
- 문헌 경로에서 I권은 만샤이어 집사(총독성채 1층), II권은 브린 인쇄소를 구매처로 표시합니다. 계열별 교관은 I권 정보에서만 표시합니다. III·IV권은 획득처에 **드랍으로 획득**으로 안내하며, 드랍 장소·적 등의 상세 경로는 표시하지 않습니다.
- 능력치 경로는 요구된 스탯별 `(현재 수치 - 10)`의 합을 표시합니다. 초기 캐릭터 보너스를 포함합니다. 위키에 별도로 기재된 레벨 도달 해금도 적용합니다.
- 문헌/능력치/레벨 중 하나로 해금해도 연결된 선행 기술의 습득과 AP는 별도로 필요합니다.
- 선행 기술은 경로별로 판정합니다. **또는**으로 나뉜 경로 중 하나를 충족하면 되며, ◆ 합류 지점으로 연결된 한 경로 안의 기술은 **모두** 필요합니다. 근검절약은 일시 휴식/상처 뜸질 중 하나, 적응성은 근검절약/응급 처치 중 하나가 필요하며 생존 의지는 응급 처치를 요구합니다.
- 트리는 원본 이미지의 선 꺾임과 보석 합류 표시를 유지합니다. 선행 기술을 습득하면 원본의 해당 연결선이 보라색으로 바뀌고, 모두 필요한 합류 지점과 그 뒤의 선은 해당 기술을 모두 습득해야 활성화됩니다. 기술을 취소하거나 과거 레벨을 선택하면 색도 그 시점에 맞게 바뀝니다. 선택한 기술의 선행 기술에는 금색 테두리가 표시되며, **해금·습득** 탭에서 각 경로의 충족 여부를 볼 수 있습니다. 한쪽 선행 기술을 취소해도 다른 유효 경로가 남아 있다면 후속 기술을 유지합니다.
- **빌드 저장** / **내 빌드**로 같은 브라우저에 최대 20개 빌드를 저장하고 불러옵니다. 자동 임시 저장도 지원합니다.
- 처음 접속하면 투자 내역이 없는 1레벨 아르나 빌드로 시작합니다. 시작 시 무료 습득 기술은 그대로 반영하며, 기존 임시 저장본이 있으면 편집하던 빌드를 이어서 엽니다.

## 데이터 범위

이미지·트리 배치 좌표·스킬별 능력치/레벨 해금 수치는 [공식 위키](https://stoneshard.com/wiki/)에서 가져왔습니다. 한국어 계열/스킬 명칭, 선행 연결, 효과 설명 및 기본 전투 수치는 사용자가 제공한 [Stoneshard Info](https://stoneshard-00.web.app/)와 대조했습니다. 사이트 전체 레이아웃이나 프로그램은 재사용하지 않습니다.

원본 출처는 `assets/sources.json`, 개별 기술의 자료 출처는 `wiki-data.json` / `game-data.js`에 기록합니다. 위키에는 페이지별 패치 차이와 개별 기술/트리 문서 사이의 차이가 있으므로 현재 게임의 완전한 재현으로 간주하지 않습니다. 예를 들어 생존의 공통 기초 기술은 트리 문서의 시작 해금 분류를 우선합니다. 참고 사이트의 한국어 스킬명 표기를 유지하며 게임 내 번역과 최종 대조가 필요합니다.

출처 URL은 자료 기록용으로 보관하며 빌더 화면에는 출처 바로가기를 표시하지 않습니다. 캐릭터명 디르윈, 능력치명 생명력, 일시 휴식 표기 및 디르윈의 최대 +3 SP 보상은 사용자 확인을 반영했습니다.

포인트 규칙은 `1레벨 SP 0 / AP 2`, 레벨업마다 각각 `+1`을 적용합니다. 디르윈의 생존 투자 3 AP마다 +1 AP와 마히르의 계열별 6 AP 투자 시 +1 AP(총 5회 제한)를 자동 계산합니다. 무료 습득 기술은 투자 포인트로 세지 않습니다. 특성 보너스는 [요르그림](https://stoneshard.com/wiki/Jorgrim), [벨미르](https://stoneshard.com/wiki/Velmir), [마히르](https://stoneshard.com/wiki/Mahir), 이벤트 보상은 [Boulder Circle](https://stoneshard.com/wiki/Boulder_Circle)을 참고했습니다. 벨미르의 최대치는 현재 모험 모드 보스 2종 기준이며 프롤로그 보스는 포함하지 않습니다.

장비·일시 버프를 포함한 최종 체력·기력·저항력 계산은 포함하지 않습니다. 환상열석의 보석 보너스는 기본 능력치 5종에 합산하지 않고 별도의 영구 효과로 표시합니다. 선택한 레벨 이전에는 특성/이벤트 보상이 적용되지 않으며, 보상 종류별로 한 번만 획득할 수 있습니다.

캐릭터 설정은 `data.js`, 가져온 스킬 자료는 `game-data.js`, 성장 계산은 `planner.js`, 효과 수식/표시는 `effects.js`, 화면 동작은 `app.js`, 디자인은 `styles.css`에서 수정합니다. 공개 데이터 형식은 `sharing.js`, 서버 연결은 `cloud.js` / `cloud-config.js`, 공개 목록·폼은 `community.js` / `community.css`입니다. 개인 저장과 임시 저장은 브라우저에 보관하며 **공개하기**를 선택한 내용만 서버로 보냅니다. 기존 초안의 저장 파일은 읽을 때 새 스킬 ID와 문헌 기록으로 변환합니다.

가져오기 스크립트는 Python 표준 라이브러리만 사용합니다. 자료를 다시 가져오려면 `scripts/import_wiki.py`, 이어서 `scripts/import_reference.py`를 실행합니다. 외부 자료는 코드로 실행하지 않고 HTML/문자열 데이터로만 파싱합니다.

`scripts/import_connections.py`는 원본 PNG의 연결선 색상 픽셀을 읽어 257개 가지의 SVG 마스크를 생성합니다. 노드의 옆으로 진입하는 선도 포함하며 원본 이미지 파일은 변경하지 않습니다.
